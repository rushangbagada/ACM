# ACM SVNIT: The Digital Archive

A high-performance, editorial-grade web portal for the ACM Student Chapter at SVNIT Surat. Built with a focus on "Cyber-Professional" aesthetics and buttery-smooth user interaction.

## 🚀 Project Description

### Overview
This project serves as the definitive digital repository for ACM SVNIT, showcasing the chapter's rich history of technical events and the minds behind them. It bridges the gap between a standard organizational website and a high-fidelity digital experience, providing both a "Team Archive" timeline and an "Event Horizon" portal.

### Architecture
The application is built on **Next.js 14** using the **App Router** for optimized routing and server-side rendering.
- **Core**: React 18 & TypeScript for type-safe, component-driven development.
- **Styling**: Tailwind CSS for a utility-first, highly customizable design system.
- **Animations**: A combination of **GSAP (GreenSock)** for high-performance scroll-triggered sequences and **Lenis** for integrated smooth scrolling.
- **Asset Management**: Leveraging **next/image** for automatic image optimization, converting high-res team assets into efficient WebP formats on the fly.

### Design Reasoning
The "Cyber-Professional" aesthetic was chosen to reflect the cutting-edge nature of Computer Science.
- **Color Palette**: A deep charcoal base (#0a0a0a) to reduce eye strain and provide a premium "pro" feel, accented with Electric Blue (#0070f3) for digital energy.
- **Glassmorphism**: Subtle translucent overlays with backdrop blurs to create depth and visual hierarchy without clutter.
- **Bento Grid**: Used in the Events and Team sections to present non-linear, data-dense information in an organized, responsive manner.
- **Editorial Typography**: Using Geist and Inter to maintain a clean, technical, yet sophisticated look.

## 🔮 Future Scope

- **CMS Integration**: Implementing a headless CMS (like Sanity or Contentful) to allow non-technical board members to upload new events and team photos without touching the code.
- **Interactive Timeline**: Enhancing the Team Archive with a 3D WebGL-based timeline or a more granular "Member Spotlight" feature.
- **Event Registration System**: Integrating a secure backend for real-time event registrations and automated digital certificate generation.
- **Live Search & Filtering**: Adding advanced searching across the event archive by year, category (Hackathon, Seminar), or speaker.
- **Member Dashboard**: A dedicated portal for active members to access resources, past workshop recordings, and internal chapter documentation.
